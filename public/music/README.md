# Game Background Music

This directory contains background music files for different games:

## Required Music Files:
- `crossword-ambient.mp3` - Soft ambient music for crossword puzzles
- `quiz-upbeat.mp3` - Upbeat music for quiz games
- `memory-focus.mp3` - Focused concentration music for memory games
- `tap-energetic.mp3` - High-energy music for tap games
- `word-calm.mp3` - Calm music for word games
- `math-concentration.mp3` - Concentration music for math challenges
- `color-playful.mp3` - Playful music for color matching
- `reaction-intense.mp3` - Intense music for reaction tests
- `fillword-peaceful.mp3` - Peaceful music for fill-the-word games

## Music Guidelines:
- All files should be in MP3 format
- Keep volume levels consistent across all tracks
- Recommended length: 2-5 minutes (will loop automatically)
- Use royalty-free or licensed music only
- Optimize file sizes for web delivery

## Fallback:
If music files are not available, games will run silently without affecting functionality.
